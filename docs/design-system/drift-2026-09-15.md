## How to read the file yourself

A `.fig` is a zip. Inside, `canvas.fig` is Figma's kiwi binary: an 8-byte
`fig-kiwi` magic, a version, then length-prefixed blocks — block 0 the compiled
kiwi schema (raw deflate), block 1 the document (**zstd** in this export;
older ones use deflate). `npm i kiwi-schema`, then
`compileSchema(decodeBinarySchema(block0)).decodeMessage(block1)` gives the
whole node tree, including `editInfo.lastEditedAt` per node. Embedded images sit
in `images/`, named by the SHA-1 that `fillPaints[].image.hash` carries.

## 2. Reported — the top bar (spec 003 owns navigation; spec 002 owns the component)

The `Top Navigation` component now has two variants, both edited 2026-09-14:

| Variant | Navigation | Account cluster |
|---------|-----------|-----------------|
| Employee | Catalog · My Requests | Request List + count · **bell** · divider · avatar, name, role |
| Admin | Requests Queue · **History** · Inventory | **bell + count badge** · divider · avatar, name, role |

Three differences from what the shell ships:

1. **A notification bell**, in both variants, with a count badge on Admin. The
   shell has none, and spec 003's FR-014 does not mention one. Needs a spec
   amendment before it is built — and a decision about what it opens, which the
   file does not draw.
2. **Profile is not a navigation item.** The `05 - Profile` screen uses the
   Employee bar with nothing marked current, so the screen is reached some other
   way — presumably the account cluster, but no affordance is drawn. Spec 003
   FR-006 puts Profile in all three navigation sets. One of the two has to give.
3. **History is a destination** in the Admin bar, and two `04 - History` frames
   exist. Spec 003's destination set has no history address for Approver or
   Supply Admin.

Unchanged and still true: the merged "Admin" identity the file draws is what
constitution II forbids and spec 003 D1 already overrides. The split stands.

Two things follow, neither of them ours to decide:

- **`Cancelled` is a seventh status.** The file's own definition: "The request
  was stopped before completion — either by the Employee (before approval) or by
  the Supply Admin (after approval, e.g. item unavailable, request no longer
  needed). A reason is required when the Approver cancels." Constitution IV
  fixes the state machine at six states and has no cancel transition;
  `docs/process-flow.md` has no cancel path and no cancellation email. Adding it
  is a **constitution amendment** (principle IV), plus spec 001 (FR-013,
  FR-014), `docs/process-flow.md`, and `src/shared/ui/status.ts`.
- **`Completed` changed colour** from the green "moving or done" tone to purple.
  That breaks the stated rule that amber waits on a human, green is moving or
  done, red is stopped — the same rule the two handover labels already bent
  (additions.md §2b). Spec 002 owns the reconciliation.

A cancel flow is drawn: `04.2 - My Requests - Cancel Request` and
`04.2 - My Requests - Cancelled`.
