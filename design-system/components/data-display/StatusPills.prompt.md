Every state a request or a stock line can be in. This is the component that carries the system's meaning — never hand-roll a coloured badge instead.

```jsx
<StatusPills status="Pending Approval" />
<StatusPills status="Rejected" />
<StatusPills availability="unavailable" />
```

Two shapes: `pill` (999px, Inter 700 / 12px, 6×10 padding) for request and stock status, `rounded` (8px, Inter 700 / 11.5px, 10px padding) for the availability chip on a supply card. Colour pairs come from the source: amber for pending/low, green for approved through completed and in-stock, red-tint for rejected/out-of-stock/unavailable.
