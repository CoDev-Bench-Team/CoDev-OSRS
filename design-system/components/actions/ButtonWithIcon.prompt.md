Chromeless glyph-plus-label button — a tertiary action with no fill or stroke.

```jsx
<ButtonWithIcon property1="default" label="Regenerate List of jobs" />
```

Variants: `default` (ink `--osrs-template-ink`) and `hover` (`--osrs-template-muted`). From the same external library as `ButtonTemplate`; Noto Sans 500 / 16px.
