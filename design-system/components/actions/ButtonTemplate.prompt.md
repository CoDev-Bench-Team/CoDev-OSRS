Outlined action button with a leading glyph and a two-state save affordance.

```jsx
<ButtonTemplate state="default" label="Save as template" />
<ButtonTemplate state="saved" />
```

Variants: `state="default"` (white fill, download glyph) and `state="saved"` (40% opacity, check glyph). Note: this family arrived from an external library and uses Noto Sans + the purple stroke `--osrs-template-purple`, not the OSRS brand red.
